# Μενού «Προσθήκη block» στον editor

## Αλλαγή
- Προσθήκη εμφανoύς κουμπιού «Προσθήκη block» στη γραμμή εργαλείων του υπάρχοντος editor.
- Μενού με επιλογές: παράγραφος, επικεφαλίδα, εικόνα, gallery 2 εικόνων, gallery 3 εικόνων, πίνακας, FACT box και scorecard.
- Κάθε επιλογή θα προσθέτει ένα αντίστοιχο, ευανάγνωστο mock block στο περιεχόμενο μέσω τοπικού state.
- Διατήρηση των υπαρχόντων formatting controls, routes, layout και λειτουργιών δημοσίευσης.

## Οπτική και αλληλεπίδραση
- Δίστηλο μενού στο desktop και μονόστηλο σε στενές οθόνες.
- Εικονίδιο, ελληνική ονομασία και σύντομη περιγραφή για κάθε block.
- Πλήρης keyboard πλοήγηση, focus states και touch-friendly στόχοι.

## Έλεγχος
- Έλεγχος σε νέο και υπάρχον άρθρο.
- Επιβεβαίωση ότι το menu ανοίγει, όλα τα blocks εισάγονται και δεν υπάρχει οριζόντια κύλιση σε mobile.
- Καμία εγκατάσταση editor framework και καμία κλήση σε backend.
