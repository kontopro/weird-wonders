# «Ήξερες ότι;» — Πλάνο υλοποίησης

## Στόχος
Ένα πλήρως responsive ελληνικό online περιοδικό για τεκμηριωμένες, απρόσμενες ιστορίες. Θα λειτουργεί αποκλειστικά με τοπικά mock δεδομένα και local storage — χωρίς βάση δεδομένων ή εξωτερικό backend.

## Οπτική κατεύθυνση
- Editorial σύνθεση με off-white φόντο, βαθύ σχεδόν μαύρο μπλε και accents σε ηλεκτρικό κίτρινο, κοραλλί και γαλάζιο.
- Ιδιαίτερη αλλά ευανάγνωστη ελληνική τυπογραφία, μεγάλες φωτογραφίες και απαλά rounded corners.
- Ξεχωριστό χρώμα και εικονίδιο για κάθε κατηγορία.
- Διακριτική κίνηση σε scroll, hover και στην αποκάλυψη του fact της ημέρας.
- Πλήρες light/dark theme με σωστό contrast.

## Σελίδες
1. **Αρχική**
   - Sticky header, desktop navigation, mobile menu, αναζήτηση, theme toggle και τυχαίο άρθρο.
   - Μεγάλο featured άρθρο και δύο trending άρθρα.
   - Διαδραστικό «Fact της ημέρας» με reveal, αντιγραφή και κοινοποίηση.
   - Οκτώ κατηγορίες, grid πρόσφατων άρθρων, top-5 δημοφιλή και newsletter με validation/success state.
2. **Άρθρο**
   - Reading progress, στοιχεία άρθρου, κεντρική εικόνα, συντάκτης, share/bookmark.
   - Πίνακας περιεχομένων, πλούσια τυπογραφία, pull quotes, fact boxes, πηγές, tags, σχετικά άρθρα και αντίδραση «Ναι / Όχι».
   - Σταθερή σήμανση ότι όλο το αρχικό περιεχόμενο είναι demo και απαιτεί επαληθευμένες πηγές.
3. **Ανακάλυψε**
   - Πραγματική αναζήτηση, κατηγορία, χρόνος ανάγνωσης, ταξινόμηση και empty state.
4. **Κατηγορίες, Δημοφιλή, Σχετικά και 404**
   - Αυτόνομες, συνεπείς σελίδες ώστε κανένας σύνδεσμος να μην είναι ανενεργός.

## Λειτουργίες
- Δομημένα mock data για τουλάχιστον 8 άρθρα, εύκολα αντικαταστάσιμα αργότερα.
- Bookmarks και συγκατάθεση cookies σε local storage.
- Random article, dark mode, copy/share, back-to-top και newsletter validation.
- Όλα τα controls θα έχουν πραγματική συμπεριφορά και προσβάσιμες ετικέτες/focus states.

## Τεχνικές λεπτομέρειες
- React + TypeScript, μικρά επαναχρησιμοποιήσιμα στοιχεία και κοινό design system με semantic tokens.
- Ξεχωριστές διαδρομές με ελληνικά slugs όπου είναι πρακτικό.
- Μοναδικά SEO/Open Graph metadata ανά σελίδα, semantic HTML και βελτιστοποιημένες τοπικές εικόνες.
- Responsive έλεγχος σε desktop και mobile πριν την ολοκλήρωση.
